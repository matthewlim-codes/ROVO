# Rovo

A mobile-first web application built for club volleyball families to seamlessly coordinate airport carpools, hotel rideshares, and tournament logistics.

## Problem

Travel tournaments involve dozens of families arriving at different times, staying at various hotels, and trying to coordinate rides via unorganized group texts. This logistical overhead causes high stress, missed rides, and wasted rental car capacity.

## Solution

Rovo acts as a dedicated logistics hub. Families can input their flight times, hotel locations, and open car seats, allowing the app to surface carpooling opportunities and match families traveling on similar schedules.

## Features

- **Mobile-First Design:** Optimized specifically for parents on the move at airports and convention centers.
- **Flight and Hotel Matching:** Input arrival windows and hotel hubs to instantly see who is landing at the same time or staying nearby.
- **Open Seat Tracking:** Families with rental cars can post available seats; families needing rides can claim them instantly.
- **Tournament Hubs:** Group coordination filtered by specific tournament events and dates.

## Tech Stack

- **Frontend:** React, Tailwind CSS
- **Build Tool:** Vite
- **Database:** LocalStorage (Prototype)
- **Tools:** Cursor, GitHub, Adobe Illustrator
